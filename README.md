# Brevo skills

Skills that teach AI agents to work with Brevo, packaged for Claude, ChatGPT, Codex, Gemini
and any agent that reads `SKILL.md`. Each skill drives the
[Brevo MCP server](https://developers.brevo.com), which handles sign-in with OAuth: no API
keys to copy anywhere.

| Skill | Status | What it does | Source |
|---|---|---|---|
| [`brevo-cli`](src/skills/brevo-cli/SKILL.md) | public | Uses the Brevo Developer CLI to manage OAuth apps, UI apps and Brevo Functions | Synced from [getbrevo/brevo-cli](https://github.com/getbrevo/brevo-cli) |
| [`email`](src/skills/email/SKILL.md) | public | Route an email request to the right email skill, after confirming the account | This repo |
| [`email-template-write`](src/skills/email-template-write/SKILL.md) | public | Write the HTML of a Brevo email (campaign, automation or transactional) with personalization | This repo |
| [`email-template-check`](src/skills/email-template-check/SKILL.md) | public | Check email HTML against Brevo's template rules and fix what fails, before it is saved or sent | This repo |
| [`email-template-to-dnd`](src/skills/email-template-to-dnd/SKILL.md) | public | Turn email HTML into a design that opens in Brevo's drag-and-drop editor, and save it as a template | This repo |
| [`email-campaign-create`](src/skills/email-campaign-create/SKILL.md) | public | Create a Brevo email campaign as a draft from finished HTML, for a chosen list and a verified sender | This repo |
| [`email-test-preview`](src/skills/email-test-preview/SKILL.md) | public | Preview a draft email and send a test of it to addresses the user names | This repo |
| [`email-brand-kit`](src/skills/email-brand-kit/SKILL.md) | public | Read the account's brand kit (logo, colours, fonts, social links) as email styles, and set it up or change it after the user approves | This repo |

Skills marked **Synced from** are edited in their source repo, not here: the next sync
overwrites local changes.

## Install

| Agent | How |
|---|---|
| Claude Code | `/plugin marketplace add getbrevo/brevo-skills`, then `/plugin install brevo@brevo-skills` |
| Codex | `codex plugin marketplace add getbrevo/brevo-skills`, then `/plugins` |
| Cursor | Add the plugin from `getbrevo/brevo-skills` in Cursor's plugin settings |
| Grok | Install the plugin from `getbrevo/brevo-skills` |
| Gemini CLI | `gemini extensions install https://github.com/getbrevo/brevo-skills` |
| claude.ai, ChatGPT, Gemini (upload) | Download the skill ZIP from the [latest release](https://github.com/getbrevo/brevo-skills/releases) and upload it in your agent's skill settings |
| Any other agent | `npx skills add getbrevo/brevo-skills` |

Every path, with each platform's limits: [docs/platforms.md](docs/platforms.md).

Each [release](https://github.com/getbrevo/brevo-skills/releases) is announced on Slack with
the skills that changed and the files to upload by hand; ask a maintainer for the channel.

## How this repo works

```
src/skills/<name>/     the skills, as written (SKILL.md, skill.json, references/)
shared/                rules every skill includes
adapters/              one build target per platform
evals/                 behaviour test cases per skill
scripts/               build, validation, safety and contract checks
schemas/               published manifest schemas the CI validates against
skills/  .claude-plugin/  .cursor-plugin/  .grok-plugin/  plugin.json  mcp.json
gemini-extension.json  GEMINI.md  catalog.json
                       generated by `yarn build`: don't edit by hand
```

One source, one version, every platform. The design is in
[docs/architecture.md](docs/architecture.md), and how to add a skill or a platform in
[CONTRIBUTING.md](CONTRIBUTING.md).

```bash
yarn install      # one dev dependency: ajv, for the schema check
yarn verify   # validate, generated files in sync, schemas, public-safety check, tests
yarn build    # regenerate every platform's files
yarn scan     # static security scan of the skill text (SkillSpector, installed with uv)
yarn new-skill <name> --owner <team> --summary "<job it does>"   # scaffold a skill
```
